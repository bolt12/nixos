# hetzner-hub, Hetzner Cloud VM (Headscale control plane + tunnel adblock DNS)

Public entry point for the fleet after the home ISP switch removed the public IP.
Two roles:

1. **Headscale control plane** (self-hosted Tailscale coordinator) on TCP 443 at
   `https://hetzner-nixos.ddns.net`, with a Let's Encrypt cert via the built-in
   ACME (HTTP-01 on port 80). Devices join with
   `tailscale up --login-server=https://hetzner-nixos.ddns.net` and from then on
   negotiate DIRECT peer-to-peer paths to each other (over public IPv6 or NAT
   traversal), so this box carries no peer traffic. It is also a tailnet node
   itself (`100.64.0.5`). Config in `headscale.nix`.
2. **Adblock resolver** (unbound + Hagezi RPZ) served over the tailnet on the
   hub's tailscale address (`100.64.0.5`). Config via the shared
   `services.adblockDns` module; hardening in `dns.nix`.

The RPi keeps Tang + a LAN-only copy of the same resolver. ninho and the laptop
resolve via the hub (`100.64.0.5`) over Tailscale, falling back to the RPi's LAN
IP when the tailnet is down.

## Files

- `disko.nix` BIOS GPT layout (1M EF02 boot partition + ext4 root, GRUB). Wipes
  the disk on install. This VM boots legacy BIOS (confirmed by pre-flight).
- `hardware-configuration.nix` generated by nixos-anywhere (stub until then).
- `networking.nix` systemd-networkd, DHCP v4 + static v6 via `fe80::1`, and the
  public firewall base (SSH only; headscale + the tailscale client open the rest).
- `headscale.nix` Headscale service + built-in Let's Encrypt, the public firewall
  ports (TCP 80/443), and this box's own tailscale client.
- `dns.nix` adblock resolver options (binds the hub tailscale address + loopback,
  refuse-by-default ACL).
- `configuration.nix` bootloader, SSH, packages, stateVersion.

## First install (from ninho or the laptop)

Prerequisite: SSH as root to the live rescue system. No hand-placed keys are
needed at install time: Headscale generates its own keys, and the tailscale
authkey is placed after the first deploy (see Bootstrap).

```bash
# 0. Pre-flight (read-only). Confirms boot mode, disk id, NIC name.
ssh root@2.28.9.140 '[ -d /sys/firmware/efi ] && echo UEFI || echo BIOS; \
  ls -l /dev/disk/by-id; lsblk; ip -o link'
#   Confirmed on this VM: BIOS, /dev/sda, eth0. disko/configuration are set for
#   BIOS + GRUB.

# 1. Install (builds locally; do NOT --build-on-remote on a small plan).
nix run github:nix-community/nixos-anywhere -- \
  --generate-hardware-config nixos-generate-config \
    ./system/machine/hetzner/hardware-configuration.nix \
  --flake .#hetzner \
  --target-host root@2.28.9.140

# 2. Commit the generated hardware config.
git add system/machine/hetzner/hardware-configuration.nix
git commit -m "hetzner: nixos-anywhere hardware config"
```

## Hetzner Cloud firewall (do not skip)

The Hetzner Cloud firewall (console, a layer separate from the NixOS firewall)
must allow inbound **TCP 22, 80, 443** (and UDP 41641 if you want the hub itself
to reach peers directly). Port 80 is required for Headscale's HTTP-01 ACME
challenge; without it the cert never issues and Headscale crash-loops. The NixOS
firewall alone cannot fix this: the cloud firewall drops the SYN first.

Also confirm the control hostname forward-resolves to this box:
`dig +short hetzner-nixos.ddns.net` must return `2.28.9.140`.

## Bootstrap (once, after the first deploy)

```bash
# on the hub:
curl -sSf https://hetzner-nixos.ddns.net/health        # cert issued, control API up
headscale users create bolt
headscale users list                                    # note the numeric id
headscale preauthkeys create --user <id> --reusable --expiration 720h
# place the key on each node (this box included) at /etc/tailscale/authkey:
printf '%s' 'tskey-...' | sudo install -D -m600 /dev/stdin /etc/tailscale/authkey
```

## Verify

SSH stays up regardless (port 22 is public, independent of the tailnet):

```bash
ssh root@2.28.9.140 headscale nodes list    # enrolled devices + their 100.64.x
tailscale status                            # peers, direct vs DERP
dig @2.28.9.140 example.com                 # MUST refuse/timeout (no open resolver)
```
